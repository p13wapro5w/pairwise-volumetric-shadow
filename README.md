# pairwise-volumetric-shadow

手电筒穿过烟雾时，光柱边缘出现一条条硬带，体积阴影每步只查一张 512 的深度图，近处物体把整条射线的透过率压成零；抖动按屏幕像素做，低分辨率下噪点连成块，时域累积又因为相机移动没重投影，拖出一条尾巴；阴影图与参与介质用了不同近远平面，光柱在墙后还在亮；烟雾密度按 3D 纹理采样，纹理坐标没随光源移动更新，光柱跟着世界轴走；半透明粒子既写深度又参与阴影，同一层烟被算两次透过率；射线步长固定，掠射时光柱出现阶梯；蓝噪声偏移在时域上不收敛，静止画面一直在闪；阴影图分辨率按相机距离选，切档时整根光柱亮度跳变；光源在介质内部时，阴影图正面剔除把整个体积当成被遮挡；多盏灯共用一个体积阴影缓冲，第二盏灯把第一盏的透过率覆盖。render/volumetric_shadow.py 是核心，tests/test_volumetric_shadow.py 15个红。要修的是：多级深度采样；蓝噪声抖动；时域重投影；近远平面统一；密度随光源更新；透明只算一次；按深度自适应步长；时域收敛；分辨率切档渐变；灯内单独处理。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
